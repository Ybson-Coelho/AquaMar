# 🐠 AquaMar

AquaMar é uma plataforma web desenvolvida para proporcionar uma experiência completa aos visitantes de um aquário. Através dela, os usuários podem explorar informações sobre os animais, acompanhar eventos e cronogramas, além de comprar ingressos de forma simples e rápida.

## 🌊 Funcionalidades

- 🎟️ Compra de ingressos online
- 🐟 Catálogo de animais do aquário
- 📖 Informações detalhadas sobre espécies marinhas
- 📅 Cronograma de eventos e apresentações
- 📱 Interface responsiva para desktop e dispositivos móveis

## 🚀 Tecnologias Utilizadas

- HTML5
- JavaScript
- Tailwind CSS
- Git & GitHub

## 🎯 Objetivo

O AquaMar tem como objetivo conectar visitantes ao mundo marinho através de uma plataforma moderna, intuitiva e acessível, facilitando o planejamento de visitas e o acesso às atrações do aquário.

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/Ybson-Coelho/AquaMar.git
```

Acesse a pasta do projeto:

```bash
cd AquaMar
```

Instale as dependências:

```bash
bun install
```

Inicie o projeto:

```bash
bun dev
```
